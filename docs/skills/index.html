Full PULSE repository

Activate all eight from the bundled local source

Included path 
gh skill install . --all --from-local \
  --agent github-copilot \
  --scope project

Bootstrap attempts this activation automatically when the current runner supports native project skills. The installed copies stay local; docs/skills/ remains canonical.

Universal skills-only installer

Install all eight without the full framework

npx skills@latest add manishtiwari25/pulse \
  --skill '*' \
  --agent github-copilot \
  --copy \
  --yes

Replace github-copilot with another supported agent. Requires Node.js 22.20 or newer.

GitHub CLI skills-only installer

Install the remote pack at project scope

gh skill install manishtiwari25/pulse --all \
  --agent github-copilot \
  --scope project

Use --scope user when the same PULSE skills should be available across repositories.

Review skill source before use. Skills run with the permissions granted to the coding agent, while PULSE repository and rollback rules remain in force.

Featured safeguards

Decide who should do the work, then make sure there is a safe way back.

Delegation intelligence

/pulse-delegation-advisor

Reads real repository token history and combines it with risk, novelty, ambiguity, reversibility, file count, and external state.

  • Lower, central, and upper token range
  • Low, medium, or high confidence
  • Agent-led, hybrid, or human-led recommendation
  • No guessed provider pricing

Recovery guardrail

/pulse-rollback

Restores a known-good state without deleting unrelated work, rewriting shared history, or guessing at production and data recovery.

  • Confirms the rollback trigger
  • Isolates only the current task
  • Stops at approval-required boundaries
  • Verifies and records recovery

The complete catalog

Eight skills cover the PULSE lifecycle.

Each bundle is model-agnostic, readable Markdown with any helper code stored beside it.

01Start

/pulse-bootstrap

Add or repair the full PULSE control plane without replacing existing code, rules, or uncommitted work.

Use for: adoption, onboarding, and incomplete setup repair.
