Recorded from the ADR-015 delivery session so the next agent who touches
`docs/scripts/pulse-dashboard.py` or its tests does not rediscover them.

1. macOS aliases `/var/folders/...` to `/private/var/folders/...`. A test
   fixture in a temp directory hashed to a different project key than the
   same directory once resolved, and the "two repositories get separate
   projections" assertion failed for the wrong reason. Fixed by resolving
   paths on both sides; lesson in `docs/memory/mistakes.md` (2026-09-04).
2. A headless Chromium-family browser (`--headless=new --dump-dom` or
   `--screenshot`) lingers after it prints on macOS, and macOS has no
   `timeout` binary. Wrap the call in `subprocess.run(..., timeout=45)` and
   accept the output already produced when `TimeoutExpired` fires; the
   render was complete.
3. `serve` deliberately has no `--now`: a live dashboard must judge claim
   expiry against the real clock, so only `index` and `snapshot` accept it.
   To browser-check the fixture repository, serve it as-is and expect the
   expiry-dependent counts to differ slightly from the fixture's frozen
   `NOW`; compare numbers through the unit tests instead.

Evidence: the fixed test suite (16 tests) and the parity snippet now written
into `docs/workflows/dashboard.md`, both run clean on this tree.
